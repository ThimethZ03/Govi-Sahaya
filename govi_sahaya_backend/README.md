# Govi Sahaya Backend API

Smart Agriculture Advisor Platform - Backend API built with Node.js, Express, and MongoDB.

## Features

- 🔐 **Authentication & Authorization** - JWT-based auth with role management
- 🔬 **Crop Doctor** - AI-powered disease detection using TensorFlow
- ☁️ **Weather Updates** - Real-time weather forecasts and alerts
- 📚 **Knowledge Hub** - Expert guides and farming best practices
- 💰 **Profit Planner** - Expense tracking and financial management
- 🛒 **Shop** - Marketplace for farming products
- 💬 **Community Forum** - Connect with other farmers
- 📧 **Notifications** - Multi-channel notifications (Push, Email, SMS)

## Prerequisites

- Node.js >= 18.0.0
- MongoDB >= 6.0
- npm >= 9.0.0
